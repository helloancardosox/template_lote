🔧 Configuração

Configure o arquivo .env com suas credenciais:

  • INFOBIP_API_KEY
  • INFOBIP_BASE_URL
  • INFOBIP_SENDER

📡 Endpoints da API

GET /api/infobip/templates

Listar todos os templates

POST /api/infobip/templates

Criar um novo template

POST /api/infobip/templates/batch

Criar múltiplos templates em lote

POST /api/templates/convert/meta-to-infobip

Converter template Meta para formato Infobip

GET /api/templates/examples

Obter exemplos de templates

📝 Exemplo de Uso

// Criar um template básico
fetch('/api/templates/create-basic', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'meu_template',
    bodyText: 'Olá {{1}}! Bem-vindo!',
    language: 'pt_BR'
  })
})
.then(res => res.json())
.then(data => console.log(data));

// Criar template no Infobip
fetch('/api/infobip/templates', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(templateData)
})
.then(res => res.json())
.then(data => console.log(data));

// Criar múltiplos templates
fetch('/api/infobip/templates/batch', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    templates: [template1, template2, template3]
  })
})
.then(res => res.json())
.then(data => console.log(data));
